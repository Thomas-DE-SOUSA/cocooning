# Notes

Les règles métier et le vocabulaire du contexte `notes` : les notes riches du couple, personnelles ou partagées, éditées à deux en temps réel.

- [Règles](rules.md) : création, visibilité, édition à deux, suppression, notification
- [Règles des dossiers](rules/folders.md) : les espaces Partagé et Privé, les dossiers classiques
- [Règles des dossiers IA](rules/ai-folders.md) : sujet, fiche type, ajout par un nom, fiche sourcée
- [Glossaire](glossary.md) : les termes des notes et leur nom dans le code
