# Architecture transverse

Ce dossier range ce qui vaut pour tout le dépôt : les raisons de l'architecture, la carte des bounded contexts, le vocabulaire commun et les conventions. L'architecture propre à un contexte va dans `docs/couple/architecture/<contexte>/`.

- [Pourquoi cette architecture](why.md) : les problèmes qu'elle résout et où vit chaque type de logique
- [Carte des contextes](context-map.md) : les bounded contexts du domaine `couple` et leurs relations
- [Glossaire](glossary.md) : les termes métier partagés et le vocabulaire d'architecture, avec leur nom dans le code
- [Conventions](conventions.md) : couches, nommage, suffixes de fichiers, packages
